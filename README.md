# Marketplace OS — демонстрация

Интерактивный финансовый кабинет для продавцов Lamoda, Wildberries и Ozon.

## Что доступно

- Финансовый пульт с фильтрами по периоду и маркетплейсу.
- Управленческий ОПиУ и расшифровка статей (демонстрационная).
- ДДС с поступлениями, расходами и переводами.
- Объяснение статуса закрытия финансового периода.

**Все цифры в демоверсии вымышлены.** Нет API-подключений, загрузки файлов, отправки данных на сервер или личных кабинетов.

Откройте `index.html` в браузере локально или включите GitHub Pages после подготовки публичного репозитория.

**Не загружайте сюда настоящие отчёты, API-ключи, личные или финансовые данные.** Исходная личная версия владельца и серверный код сюда не добавлены.

Полноценная многопользовательская версия Marketplace OS находится в разработке и не прошла окончательную независимую финансовую и security-проверку.
