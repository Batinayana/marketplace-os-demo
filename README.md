# Marketplace OS · Public Demo v3

Открыть сайт: https://marketplaceos-app.github.io/

Интерактивная демонстрация финансовой аналитики для продавцов Lamoda, Wildberries и Ozon.

## Что есть в демоверсии
- Нейтральная финансовая палитра, графитовая боковая панель, адаптивный интерфейс.
- Финансовый пульт с переключением площадки, года и месяца.
- ОПиУ, ДДС, контроль закрытия периодов и детализация показателей.
- Разделение закрытых демонстрационных месяцев и предварительных периодов.
- Все числа и демонстрационная компания **вымышлены**.

## Важно
Это статический сайт, а не промышленный SaaS. Он не принимает документы пользователей, не подключает API маркетплейсов и не обрабатывает их финансовые данные. Нельзя загружать в публичный репозиторий личные данные, отчёты, токены, ключи или закрытый серверный код.

Реальные финансовые результаты должны подтверждаться закрывающими документами, а API использоваться для оперативных метрик. ДДС и ОПиУ необходимо считать отдельно.

## Следующие этапы
1. Создать отдельный **приватный** репозиторий `marketplace-os-core` внутри организации `marketplaceos-app`.
2. Настроить серверную часть, базу данных, регистрацию и изоляцию организаций.
3. Подключить импорт закрывающих документов с сохранением источника каждой цифры.
4. Поочерёдно реализовать Lamoda → Wildberries → Ozon, сверить расчёты с эталонными закрытыми периодами.
5. Защитить загрузку файлов, API-ключи и операции, провести тестирование и только затем открыть закрытую бету.

Публичная демоверсия и приватная клиентская система должны оставаться отдельными проектами.
